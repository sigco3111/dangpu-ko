> 범인, 선문, 마종, 요족이 전쟁 중입니다. 당신은 혈살종의 잡역 구역에 전당포를 열었습니다.
> 세는 이레마다 오릅니다 — 집법당에 끌려가기 전에 가게 지계를 사두세요.

복면을 한 선문 검객이 축기단을 팔러 와서는 슬쩍 밀서의 행방을 묻습니다. 범인 잡역이 누구의 무덤인지 모를 곳에서 파낸 물건을 바구니째 들고 옵니다. 문 밖에서는 요족의 눈이 어둠 속에서 빛납니다.

**착한 사람이 될 수도 있습니다. 다만 여기서는, 착한 사람이 다음 주 세를 못 낼 때가 있을 뿐이죠.**

## 이런 일을 하게 됩니다

<table>
<tr>
<td width="55%" valign="top">

**🔍 요괴 거울로 진품과 가짜를 가려내기**<br>
단약, 옥패, 오래된 거울 — 위조품이 사방에 있습니다. 물건 위로 거울을 밀면 위조된 자리가 빛납니다.

**🎭 진실을 말할지 말지는 당신의 선택**<br>
진품을 가짜라고 우기고 헐값에 사고, 가짜를 진품으로 속여 팔기 — 현장에서 들키지만 않는다면요.

**🗡️ 힘이 된다면, 문을 걸어 잠그세요.**<br>
당신의 수련이 손님보다 높다면 카운터에서 바로 덮칠 수 있습니다. 영석도, 물건도, 그의 혼까지 전부 당신 것 — 아무도 보지 않았다면요.

**🌙 밤에는 단로와 고충 항아리, 그리고 도굴**<br>
단약과 법기를 제련하고, 고충을 항아리에 봉해 고왕이 나머지를 집어삼키게 하거나, 난장판을 뒤져 보물을 캐세요. 위험한 곳일수록 소득은 커집니다.

**👁️ 네 세력을 서로 이전투구시키기**<br>
범인, 선문, 마종, 요족은 저마다 성정이 다르고, 집법당은 쉬지 않고 당신을 주시합니다. 구역의 모든 사람이 당신이 한 일을 기억합니다.

## 엔딩: 이기는 것 자체가 아이러니

지계를 살 만큼 모으세요 — 그다음 지계세, 날인 비용, 집법당의 "보호비"가 남은 영석과 물건을 하나하나 긁어가는 걸 지켜보게 됩니다.

게임이 끝나면, 이번 판에 당신이 한 모든 일로 성격 도표를 그려 칭호를 붙여줍니다:

> **웃는 사기꾼** — 카운터에서는 싱글벙글, 등을 돌리면 가짜를 진품으로 팔아넘긴다. 이웃들은 당신을 정직한 장사치라고 한다 — 아직 들통나지 않았을 뿐.

당신은 어떤 칭호를 받게 될까요?
