## 하루를 보내는 법

1. **아침**: 임대료 결제일에는 먼저 세를 거둔다. 행상, 시세, 귀시의 물건이 아침에 바뀐다.
2. **낮에 문을 열고 손님 맞기**: 손님은 사러 오고, 팔러 오고, 감정을 부탁하러 온다. 손님 한 명이 한 번에 몇 가지 물건을 이어서 흥정할 수 있다.
3. **파장**: 밤에는 노획을 나가거나, 귀시에 가거나, 폐관할 수 있다.
4. **밤**: 설비가 「공방」의 순서대로 영력을 소모하며 돌아간다. 너는 가부좌를 틀고 쉬며 체력과 정신을 회복한다.

- 하루에 대략 **{{ T.probe.customers() }}**명이 온다. [[upgrade:sign]]을 달면 한 명이 더 오고{{! (() => { const a = T.probe.customers(); fresh(); itemsIn('display').forEach(destroyItem); S.upgrades.sign = true; return customerCount() === a + 1; })() }}, 진열장에 값나가는 물건을 둘수록 오는 사람도 는다.
- **진열장이 어떤 손님이 오는지를 결정한다**: 물건을 하나 두면 손님의 {{ pct(displayPull(1)) }}가 그것을 보고 오고, 많이 둘수록 높아져 최대 {{ pct(displayPull(99)) }}다. 물건을 보고 온 사람은 더 참을성 있고, 예산도 넉넉하고, 값도 후하게 부른다.

- [[item:yao_core]], [[item:beast_hide]]를 내놓으면 요족의 빈축을 산다. 선문 금물, 마종 금약을 내놓으면 집법당을 부른다([집법당과 순찰](law.md) 참고).

## 흥정과 감정

- 손님이 부르는 값은 물건의 바닥값, 그날의 시세, 그 족속에서의 네 명성, 너와의 호감, 난도의 가격 배율을 따른다. 너무 세게 부르면 깎거나 휙 돌아선다. 화면에는 성사, 흥정, 돌아섬의 세 가지 가능이 표시된다.
- **몇 개나 원하는지**는 찾아온 이유에 적혀 있다. 단약, 영음, 부적, 영재처럼 쓰면 없어지는 것은 흔히 두세 개, 많아야 {{ wantNeedMax('consume') }}개를 찾는다. 대장장이, 단사, 부사, 고충 기르는 이 같은 장인은 제 업의 재료를 사러 와서 많아야 {{ wantNeedMax('craft') }}개. 법기, 진완처럼 오래 쓰는 것은 대개 하나, 많아야 {{ wantNeedMax('gear') }}개. 애타게 찾는 것, 진열장을 보고 온 것, 상처를 고칠 약은 하나뿐이다. 딱 맞지만 일부러 찾는 게 아닌 것은 {{ pct(SIDE_BUY) }}만 쳐주고, 많아야 {{ SIDE_MAX }}가지를 곁들여 산다. 원하는 개수를 채운 뒤에 더 올려놓으면 쌓아두는 재고로 값을 깎아 {{ pct(EXTRA_BUY) }}만 쳐서 받고, 행상의 매입가 아래로는 내려가지 않는다.{{! wantNeedMax('gear') === 2 && EXTRA_BUY < SIDE_BUY }}
- **총액은 그의 주머니 사정을 넘지 않는다**. 값이 주머니의 {{ pct(PURSE_EASY) }}를 넘어가면 점점 아까워하고, 돈이 모자라면 많아야 주머니의 {{ pct(PURSE_OFFER) }}까지 깎는다.
- **급한 것에는 값을 따지지 않는 편**: 상처나 중독이 있는 사람은 맞는 약을 보면 상처·독이 한 중 깊어질 때마다 {{ pct(CURE_MUL) }}를 더 낸다. 애타게 찾던 것, 중독이 도진 한 모금도 마찬가지라 높게 불러도 쉽게 돌아서지 않는다. 장물이나 금지품을 급히 처분하려는 파는 쪽도, 쫓기는 신세도, 궁지에 몰린 이도 흥정할 겨를이 없다.
- **네 마음대로 할 수 있는 사람** — 네 고충에 걸렸거나, 식해에 네 혼인이 심어졌거나, 정고가 너를 인정한 사람 — 은 어떤 값이든 받아들인다. 다만 주머니에 없는 돈은 못 낸다. 물건에 흠이 있어도 면전에서 들추지 못한다.
- **네 단계 자동 제시가**는 눈앞의 손님에 맞춰 그때그때 계산한다: 양보와 공정은 그가 생각하는 공정가를 따르고, 이익은 그가 돌아설 확률이 백분의 일이 안 되는 최고가, 후려침은 열에 하나쯤 손을 털고 가는 값이다. 모두 그가 낼 수 있는 돈을 넘지 않는다. 참을성이 적을수록 같은 값에도 더 쉽게 얼굴을 붉힌다. 값을 영석 한 닢 움직일 때마다 세 가지 가능도 조금씩만 움직인다.{{! PRESET_SAFE < 0.01 && PRESET_BOLD >= 0.08 && PRESET_BOLD <= 0.1 }}
- 살 때도 파는 사람은 거짓말을 한다: 하자품, 위작, 장물도 좋은 물건이라고 둘러댄다. **감정**(조요경 사용)은 품상과 진위를 꿰뚫는다. 거울이 좋을수록 더 깊이 본다.
- 남의 물건을 감정해주고 감정료를 받는다. [[upgrade:master]]를 갖추면 감정료가 두 배이고 거짓말도 더 잘 통한다.
- 위작을 진품처럼 팔 수도 있고, 사실대로 말할 수도 있다. 사는 쪽의 눈썰미가 좋으면 그 자리에서 간파하거나, 돌아간 뒤에야 알아채고 찾아와 따진다.
