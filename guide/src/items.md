# 물품 도감

[홈으로](README.md)

바닥값은 중간 품상의 어림값이다. 실제로 얼마에 팔리는지는 품상, 당일 시세, 전황, 사는 사람이 누구인지에 따라 달라진다([경영](shop.md) 참고). 차지 칸은 창고와 진열장에서 차지하는 가로×세로다.

- **선문 금물**, **마종 금약**: 내놓으면 집법당을 부른다([집법당과 순찰](law.md) 참고).
- **섞을 수 있…**: 다른 물건에 몰래 섞을 수 있다([인물과 파벌](people.md) 참고).
- **전시 인상**, **사치**: 전황을 따라 오르내린다([절기와 전황](calendar.md) 참고).
- **구하러 가기**: 제조법 재료를 맞추려 할 때 스스로 갈 수 있는 출처. 대체로 **하급** 물건은 살 수 있거나, 위험하지 않은 곳의 노획으로 나온다. **중급**은 험지("험" 표시)를 뒤져야 하고, **고급**은 공훈 교환과 기연에 의존한다. 출처가 적히지 않은 것은 설비로 직접 만들거나([설비와 제조법](production.md) 참고), 손님이 팔러 오기를, 기연을 기다려야 한다. 모든 제조법과 첨가물은 착실히 모으기만 하면 만들 수 있다 — 이 점은 `tools/playtest/behaviors.mjs --check`가 정상 경로만 쓰는 모의 플레이어로 검증한다.
