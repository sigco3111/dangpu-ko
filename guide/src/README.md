# 마문 전당포·출처 불명 공략

너는 마도 종문 혈살종의 잡역 구역에 전당포를 열었다. 세는 회차마다 오른다. 영석을 모아 가게 문서를 사면 이긴다. 그 전에 집법당에 붙잡히거나, 세를 밀려 쫓겨나거나, 목숨을 잃지 마라.

> 이 공략의 숫자, 이름, 제조법은 프로그램이 게임 코드에서 직접 꺼내와 코드와 대조한 것이다. 코드가 바뀌면 공략도 다시 생성해야 하고, 맞지 않으면 검사에서 걸러진다. 그래서 여기 적힌 것이 지금 게임의 모습 그대로다.

## 이기는 법

- 보통 난도에서 가게 문서는 **{{ deedPrice() }} 영석**이다(다른 난도는 [시작과 난도](start.md) 참고). 이야기에서 옳은 사람을 도우면 문서 값이 내려가기도 한다.
- 문서를 사는 순간, 소유 이전 규비가 남은 영석과 가게의 물건을 전부 긁어간다: 가게는 네 것이 되고, 너는 다시 무일푼이 된다.{{! (fresh(), S.stones = deedPrice() + 500, buyDeed(), S.over && S.over.win && S.stones === 0) }}

## 지는 법

| 결말 | 이렇게 온다 |
| --- | --- |
| **옥에 갇힘** | 집법당 주시가 {{ T.probe.heatLimit() }}까지 차오른다([집법당과 순찰](law.md) 참고) |
| **쫓겨남** | 세를 못 내고, 유예 {{ T.probe.rentGrace().days }}일이 지나도 못 낸다([경영](shop.md) 참고) |
| **중상으로 사망 / 독발사** | [[cond:injured]] 삼중, [[cond:poisoned]] 삼중일 때 치료하지 않는다([상처와 독, 치료와 죽음](health.md) 참고) |

호신부가 있으면 위의 어떤 결말도 한 번은 면한다. 호신부는 네가 도운 사람이 출세해서 돌아와 은혜를 갚으며 주는 것이다([인물과 파벌](people.md) 참고).

## 이 공략을 관리하는 법

소스 파일은 `guide/src/`에, 생성된 공략은 `guide/`에 있다. 소스나 게임 코드를 고친 뒤에는:

- `node tools/guide/guide.mjs build`로 다시 생성
- `node tools/guide/guide.mjs check`로 대조: 참조가 존재하는지, 단언이 성립하는지, 생성물이 코드와 일치하는지, 코드에 새로 추가된 출신·설비·장소·상태·인물·물품이 공략에 실렸는지 확인

작성법은 `tools/guide/guide.mjs` 앞부분의 설명 참고.
